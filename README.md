# StreamStore Kafka

A **real-time order streaming dashboard** built with Apache Kafka, FastAPI, and WebSockets. Orders are generated by a simulator, streamed through Kafka, consumed by a FastAPI backend, and displayed on a live dashboard with charts and statistics.

## Architecture

```
┌─────────────┐     ┌──────────────────┐     ┌─────────────────┐     ┌──────────────────┐
│  Simulator   │────>│   Kafka Broker   │────>│  FastAPI + WS   │────>│    Dashboard     │
│ (producer)   │     │  (Docker/KRaft)  │     │   (consumer)    │     │  (HTML/Chart.js) │
└─────────────┘     └──────────────────┘     └─────────────────┘     └──────────────────┘
     orders              Topic: orders          WebSocket push          Real-time UI
```

### Components

| Component | File | Description |
|-----------|------|-------------|
| **Simulator** | `simulator.py` | Generates random orders with varied users, products, and quantities |
| **Kafka** | `docker-compose.yaml` | Apache Kafka broker in KRaft mode (no ZooKeeper) |
| **Backend** | `backend/app/main.py` | FastAPI server that consumes from Kafka and pushes via WebSocket |
| **Dashboard** | `frontend/` | Real-time web dashboard with live order feed and charts |
| **Producer** | `producer.py` | Simple single-order producer (CLI) |
| **Tracker** | `tracker.py` | Simple CLI consumer for debugging |

### Tech Stack

- **Event Streaming:** Apache Kafka (KRaft mode)
- **Backend:** Python, FastAPI, WebSockets, confluent-kafka
- **Frontend:** HTML, CSS, JavaScript, Chart.js
- **Infrastructure:** Docker Compose

## Prerequisites

- [Docker](https://docs.docker.com/get-docker/) and [Docker Compose](https://docs.docker.com/compose/install/)
- Python 3.8+

## Getting Started

### 1. Start Kafka

```bash
docker compose up -d
```

Wait a few seconds for Kafka to initialize.

### 2. Install Python dependencies

```bash
pip install -r requirements.txt
```

### 3. Start the dashboard backend

```bash
uvicorn backend.app.main:app --reload --port 8000
```

Open **http://localhost:8000** in your browser to see the dashboard.

### 4. Start the order simulator

In another terminal:

```bash
python simulator.py
```

Orders will start appearing on the dashboard in real time.

## Dashboard Features

- **Live Order Feed** — orders appear instantly as they are produced
- **Orders Timeline** — line chart showing order volume over time
- **Top Products** — doughnut chart of most ordered products
- **Revenue by Product** — horizontal bar chart of revenue per product
- **Stats Cards** — total orders, items sold, revenue, and average order value
- **Connection Status** — WebSocket connection indicator with auto-reconnect

## CLI Tools

You can also use the original CLI tools:

```bash
# Send a single order
python producer.py

# Watch orders in the terminal
python tracker.py
```

## Configuration

| Variable | Default | Description |
|----------|---------|-------------|
| `KAFKA_BOOTSTRAP_SERVERS` | `localhost:9092` | Kafka broker address |
| `KAFKA_TOPIC` | `orders` | Topic name for orders |
| `KAFKA_GROUP_ID` | `order-tracker` | Consumer group ID |

## Useful Kafka Commands

```bash
# List topics
docker exec -it kafka kafka-topics --list --bootstrap-server localhost:9092

# Describe topic
docker exec -it kafka kafka-topics --bootstrap-server localhost:9092 --describe --topic orders

# Read all messages
docker exec -it kafka kafka-console-consumer --bootstrap-server localhost:9092 --topic orders --from-beginning
```
